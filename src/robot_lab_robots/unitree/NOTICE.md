# Unitree robot descriptions: license notice

The `*_description` directories here are Unitree Robotics' robot
descriptions (URDF/xacro, meshes), vendored from Unitree's ROS description
repositories. They are distributed under the BSD 3-Clause License of
HangZhou YuShu TECHNOLOGY CO., LTD. ("Unitree Robotics"); the license text
is in [LICENSE](LICENSE).

That is the same text as `../_upstream/Awesome-URDFs/LICENSE`, which ships
with the Unitree models in that collection. Several vendored `package.xml`
files still say `TODO` for the license, a leftover of Unitree's catkin
template, not a different license.

The file was added on 2026-10-13, when `scripts/asset_attribution.py` found
that these assets had no license file in the tree. BSD-3-Clause requires the
notice to accompany redistributed source.
