# Robot Lab completion and storage audit — 2026-10-02

Baseline: `2a0aae2`, before this audit's documentation/status changes, Jetson
AGX Orin / ROS 2 Humble. The repository is **partial**. Several October 1
completion reports describe configuration or demonstration frameworks as
finished runtime qualification. Their green counts cannot support the full
ROADMAP acceptance criteria.

This audit inspected source, ledger, generated reports and recorded trial
artifacts. It executed three read-only demonstration probes, verified storage
relocation and ran the checks recorded in the accompanying evidence. It did
not rerun every historical simulator mission, perform a clean-host install,
or operate physical hardware.

## Storage result

The drone's PX4 source/build tree already lived at
`/workspace/molar/px4/PX4-Autopilot`. The internal-disk problem was dormant
trial output under `/tmp`: **65 paths, 15.79 GiB**, including repeated pxh
prompt logs. Those were copied and SHA-256/metadata verified on the SSD before
replacing the old paths with symlinks and removing the verified internal copy.
Internal available space grew from **0.63 to 16.42 GiB** (99% → 70% used).
No trial content was discarded; no active process/socket or system library was
relocated.

Use [STORAGE](../STORAGE.md) and `source scripts/ssd_env.sh` for new trials.
