# R10 marine implementation — October 15, 2026

Later continuation: [native Tethys AUV and corrected marine physics](auv-2026-10-15.md)
now provide a separate actual AUV/reef and positive-added-mass ROV/tank receipt.
The numbers below retain their original source scope; they are not relabeled
as measurements of the changed plant. Complete AUV initial integration is
now implemented experimentally; its broader qualification remains open.

Baseline `aa72d24`, Jetson AGX Orin/aarch64, ROS 2 Humble, Gazebo Fortress 6.
R10.4/R10.5/R10.8 remain **partial**. One authored complete ROV, five physical
water worlds, source-derived force allocation, bounded depth/heading/manual
control, Stop/watchdog and the normal Launch/Registry/Marine GUI workflow are
implemented. [Operator and agent guide](../tutorials/marine-rov.md).

The actual normal-GUI tank run records 227 state samples and 997 body samples
at its final observation. With neutral connection all eight force commands
are zero. Arming holds about 1 m depth; a four-second latched forward input
moves the body 0.2921 m by its input-end observation, followed by physical
braking. Depth Down changes actual depth from 1.0004 m to 1.1937 m for a
1.2003 m target; Depth Up returns it to 1.0067 m for a 1.0003 m target.
Stop zeros all eight force requests and disarms. Its observed downward
velocity afterward is 0.0223 m/s, consistent with passive negative buoyancy;
zero thrust is not a stationary-body claim. Launch exits cleanly with code 0.

The current controller observer uses actual simulator poses and numerical
velocity, not independent underwater localization. Ideal pressure is labeled
as pose-derived emulation. Native IMU/RGB-D and real rotor joint-state bridges
are implemented, but this run did not instrument independent sensor rates or
contacts. Camera appearance does not model calibrated underwater optics.
The other four worlds are installed geometry, not measured missions.

The first attempt failed before plant startup because an inherited parent
`spawn_*:=auto` reached numeric conversion in the child launch. The fix ignores
that sentinel and retains only explicit finite overrides. The retained run
also contains an unused fabricated `map_yaml` argument; final command
generation omits it for registered underwater worlds. That GUI-only correction
does not change the measured plant/controller source. A KDL root-inertia
warning is retained; no launch ERROR or Traceback occurred in the second run.
